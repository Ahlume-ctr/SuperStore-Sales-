# Retail SuperSales Analysis Dashboard

## Project Overview

The Retail SuperSales Analysis Dashboard is a modern business intelligence project designed to transform raw retail transaction data into actionable business insights. This project focuses on analyzing sales performance, customer behavior, product efficiency, regional trends, and profitability using SQL powered data analytics and an AI-assisted smart dashboard.

The project was developed using SQL in Databricks for data cleaning, transformation, and analysis, while Lovable was used to engineer an interactive executive-style dashboard for data visualization and business reporting.

---

## Business Problem

Retail businesses generate large volumes of transactional data daily, but raw data alone provides little strategic value without proper analysis. Businesses often struggle to:

* Identify top-performing products and categories
* Track revenue and profitability trends
* Understand customer purchasing behavior
* Detect weak-performing regions or segments
* Monitor operational performance efficiently
* Convert raw sales data into actionable insights

This project solves these challenges by building a centralized analytics dashboard that enables quick decision-making through insightful visualizations and performance tracking.

## SQL Techniques Used

The project involved extensive SQL-based data preparation and analysis using functions such as:

* `CAST()`
* `TRY_CAST()`
* `ROUND()`
* `CONCAT()`
* `SPLIT()`
* `GET()`
* `GROUP BY`
* `ORDER BY`
* Aggregate Functions
* Filtering & Sorting Operations

These techniques were used to clean inconsistent data, transform raw datasets, improve data quality, and generate analytical outputs for dashboard integration.
